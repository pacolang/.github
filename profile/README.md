# Paco

Paco is a programming language for building highly organized systems without the complexity of system-level languages or the weight of enterprise/OOP frameworks.

## Repositories

- [paco](https://github.com/pacolang/paco) — the compiler, runtime and stdlib
- [tensor](https://github.com/pacolang/tensor) — tensor type, operations and derivatives
- [math](https://github.com/pacolang/math) — Matrix and DataFrame, built on `tensor`
- [blas](https://github.com/pacolang/blas) — BLAS binding, an optional accelerator for `tensor`'s matmul
- [llvm-build](https://github.com/pacolang/llvm-build) — pinned LLVM builds used by the compiler
- [examples](https://github.com/pacolang/examples) — example Paco programs
- [rfcs](https://github.com/pacolang/rfcs) — design decisions for the language and ecosystem

Design and ecosystem changes are proposed as RFCs in [pacolang/rfcs](https://github.com/pacolang/rfcs).
